# Experimento: atractivo estético y ayuda a animales

Inicio rápido (requiere Python 3):

    cd experimento-animales
    python3 -m http.server 8000
    # abrir http://localhost:8000

Edita únicamente `js/config.js` (animales, parejas, parámetros, endpoint).
La documentación completa está en `PROTOCOLO.md`.
